# Backend модуля «Охрана труда»

Структура для дальнейшего развития как независимого модуля экосистемы.

## Планируемые компоненты

- API для офисов, документов, СОУТ, обучений
- Импорт чек-листа из Excel
- Расчёт индекса соответствия
- Система уведомлений
- Интеграция с Active Directory

## Рекомендуемый стек

- Python FastAPI / Django или Node.js NestJS
- PostgreSQL
- Redis (кэш и очереди уведомлений)
