# Портал «Охрана труда»

Отдельный модуль экосистемы для управления охраной труда, пожарной безопасностью, ГО ЧС, СОУТ и сопутствующими процессами.

## Архитектура

- **Frontend** — веб-интерфейс (прототип в `frontend/`)
- **Backend** — API и бизнес-логика (структура в `backend/`)
- **Документы** — чек-лист обязательных документов с импортом из Excel
- **Аналитика** — индекс соответствия, графики, уведомления

## Роли

- **Супер-админ** — полный доступ ко всем офисам
- **Ответственный офиса** — работа со своими офисами

## Запуск с Docker

```bash
docker compose up --build
```

Приложение будет доступно по адресу: http://localhost:8080

## Запуск без Docker

Откройте `frontend/index.html` в браузере.

## Перспектива роста

Модуль спроектирован как независимый сервис экосистемы:
- Отдельный API
- Импорт чек-листов
- Интеграция с Active Directory
- Расширяемая модель данных по офисам
- Готов к добавлению backend-сервиса и PostgreSQL в docker-compose
