# Архитектура модуля

## Иерархия

Супер-админ → Офисы (множество)

## Модули

- Охрана труда
- ГО ЧС
- Пожарная безопасность
- Электробезопасность
- Документы и журналы (чек-лист)
- Обучение и аттестация
- СОУТ
- ОПР (риски)
- Уведомления
- Обратная связь
- Инструкция
- Тренинг обучения

## Компоненты

- **Портал** (React + Vite, `src/`) — раздаётся nginx, ходит в API по `/api`
- **Бэкенд** (FastAPI, `backend/`) — разбор таблиц, расчёт показателей, API
- **БД** (PostgreSQL) — офисы, загрузки чек-листов, позиции

## Импорт чек-листа (сводной таблицы)

Excel-файл «Чек-лист обязательных документов» загружается на странице
«Документы» и привязывается к офису по полю «Номер офиса». Каждая загрузка
сохраняется как снимок; актуальная (с самой поздней датой проверки) задаёт
индекс соответствия офиса = доля документов со статусом «Есть».

Подробно: [checklist-import.md](checklist-import.md).
