# Архитектура модуля

## Иерархия

Супер-админ → Офисы (множество)

## Модули

| Модуль | Состояние |
|---|---|
| Документы и журналы (чек-лист) | ✅ загрузка сводной таблицы, индекс соответствия, дашборд |
| СОУТ | ✅ ручной ввод, сроки, предупреждения |
| ОПР (риски) | ✅ ручной ввод, сроки, предупреждения |
| Охрана труда, Пожарная безопасность, Электробезопасность, ГО ЧС | данные — из чек-листа по разделам; отдельные страницы — заглушки |
| Обучение и аттестация, Уведомления, Инструкция, Тренинг обучения | не реализованы |
| Обратная связь | FAQ (статичный) |

Как добавить новый отчёт или модуль: [developer-guide.md](developer-guide.md).

## Компоненты

- **Портал** (React + Vite, `src/`) — раздаётся nginx, ходит в API по `/api`
- **Бэкенд** (FastAPI, `backend/`) — разбор таблиц, расчёт показателей, API
- **БД** (PostgreSQL; для разработки и тестов — SQLite) — офисы, загрузки
  чек-листов и их позиции, записи СОУТ и ОПР

## Импорт чек-листа (сводной таблицы)

Excel-файл «Чек-лист обязательных документов» загружается на странице
«Документы» и привязывается к офису по полю «Номер офиса». Каждая загрузка
сохраняется как снимок; актуальная (с самой поздней датой проверки) задаёт
индекс соответствия офиса = доля документов со статусом «Есть».

Подробно: [checklist-import.md](checklist-import.md).

## СОУТ и ОПР

Сведения о специальной оценке условий труда и оценке профессиональных рисков
вносятся вручную по каждому офису (история записей). Портал считает сроки
(5 лет СОУТ от ФГИС, сроки внеплановой СОУТ, 30 дней на ознакомление, пересмотр
ОПР) и выводит предупреждения на страницах разделов и на дашборде.

Подробно: [sout-opr.md](sout-opr.md).
