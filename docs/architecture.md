# Архитектура модуля

## Иерархия

Супер-админ → Офисы (множество)

## Модули

- Охрана труда
- ГО ЧС
- Пожарная безопасность
- Электробезопасность
- Документы и журналы (чек-лист)
- Обучение и аттестация
- СОУТ
- ОПР (риски)
- Уведомления
- Обратная связь
- Инструкция
- Тренинг обучения

## Импорт чек-листа

Excel-файл с позициями документов привязывается к офису. Статусы обновляют индекс соответствия.
