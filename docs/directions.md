# Пожарная безопасность, электробезопасность, ГО и ЧС

Три направления с ручным вводом. У каждого офиса по каждому направлению одна карточка:
ответственный офиса заполняет её на странице направления, портал считает сроки,
подсвечивает просрочки и передаёт состояние в дашборд.

## Где что лежит

| Что | Файл |
| --- | --- |
| Поля, правила сроков, расчёт состояния | `backend/app/directions.py` (`SPECS`, `*_FIELDS`, `*_CHECKS`) |
| Хранение | таблица `office_directions` (`office_id`, `kind`, `data` JSON) — `models.OfficeDirection` |
| API | `backend/app/main.py`, раздел «Пожарная безопасность, электробезопасность, ГО и ЧС» |
| Страница | `src/pages/Direction.jsx` — форма строится по спецификации с бэкенда |
| Дашборд | столбцы «ПБ», «ЭБ», «ГО ЧС» в тепловой карте, строки в блоке «Оценки и направления», общие предупреждения |
| Тесты | `backend/tests/test_directions.py` |

## API

| Метод | Путь | Назначение |
| --- | --- | --- |
| GET | `/api/directions` | Список направлений и их поля |
| GET | `/api/directions/{kind}/spec` | Поля формы (`kind` = `fire` / `electro` / `go`) |
| GET | `/api/directions/{kind}` | Состояние по всем офисам |
| GET | `/api/offices/{code}/directions/{kind}` | Карточка офиса: данные, сроки, замечания |
| PUT | `/api/offices/{code}/directions/{kind}` | Сохранить карточку (полная замена данных) |

Номер офиса в пути кодируется `encodeURIComponent` (допустимы пробелы и `/`).
Ошибки ввода — `422` с `detail.errors[]`.

## Состояния офиса

| Состояние | Когда |
| --- | --- |
| `ok` — В норме | Нет замечаний |
| `soon` — Скоро срок | До ближайшего срока меньше `DIRECTIONS_WARN_DAYS` (по умолчанию 30 дней; для частых событий — своё окно) |
| `attention` — Требует внимания | Есть некритичные замечания (не заполнено, не утверждено) |
| `overdue` — Просрочено | Есть критичное замечание: срок прошёл, нет ответственного, просроченная I группа |
| `none` — Нет данных | Карточка не заполнялась |

## Правила по направлениям

**Пожарная безопасность** (приказ МЧС № 1120, ППР — ПП РФ № 1479): ответственный назначен;
ДПО ответственного — раз в 5 лет (регламент компании); инструкция о мерах ПБ; планы эвакуации;
распределение обязанностей с арендодателем; проверка сигнализации — раз в год, если отвечает компания;
перезарядка огнетушителей — по дате; осмотр огнетушителей — раз в квартал;
повторный противопожарный инструктаж — раз в год, при 50+ человек в помещении — раз в полгода;
тренировка по эвакуации — раз в полгода, если есть планы эвакуации.

**Электробезопасность** (приказ Минтруда № 903н): указано, чья сеть; если компании — ответственный
за электрохозяйство с группой не ниже IV и проверкой знаний раз в год; присваивающий I группу —
группа не ниже III; программа и перечень должностей утверждены; I группа по офису — раз в год;
просроченная I группа у сотрудников — критично; обход офиса — ежемесячно; неустранённые нарушения.

**ГО и ЧС** (ПП РФ № 841, № 1485): уполномоченный назначен; обучение уполномоченного и руководителя —
раз в 5 лет; программа инструктажа; ежегодный инструктаж по ЧС; новички без вводного инструктажа
по ГО — критично; учения раз в год; памятка; план ГО — только для категорированных организаций.

## Как добавить поле или правило

1. Добавьте поле в `*_FIELDS` (`_f(key, label, type, section, hint, options)`; типы:
   `text`, `textarea`, `date`, `int`, `bool`, `enum`).
2. Если по полю нужен срок или проверка — добавьте правило в `*_CHECKS`.
3. Добавьте тест в `test_directions.py`. Фронтенд менять не нужно: форма строится по спецификации.

Старые карточки при этом не ломаются: неизвестные поля отбрасываются, новые считаются незаполненными.
